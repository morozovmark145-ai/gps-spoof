# GPS Spoof

Приложение для iPhone (iOS 17.4+), которое подменяет геопозицию прямо с телефона. Работает без джейлбрейка и без компьютера после настройки.

Механизм: приложение подключается к сервису разработчика DVT LocationSimulation на самом iPhone через петлевой VPN LocalDevVPN. Связь с устройством идёт через библиотеку [idevice](https://github.com/jkcoxson/idevice) (MIT).

## Сборка

GitHub Actions собирает неподписанный `GPSSpoof.ipa` на macOS-раннере при каждом пуше в `main`. Файл появляется в разделе Releases. Подпись делается в KSign.

## Настройка на iPhone

1. Режим разработчика: Настройки → Конфиденциальность и безопасность → Режим разработчика.
2. Pairing-файл: на ПК программой idevice_pair (iDevicePair) по кабелю. Файл перекинуть на iPhone.
3. В приложении: шестерёнка → выбрать pairing-файл.
4. LocalDevVPN из App Store, включить.
5. Точка на карте → «Телепорт». Разрешить геолокацию «Всегда», чтобы подмена держалась в фоне.

Pairing-файл перестаёт работать после сброса или обновления iOS. Его надо создать заново.
